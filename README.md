# Real-Life Language Coach 🌏

**A practical Korean & English learning Skill, guided in Chinese.**

以真实生活为中心的中英韩语言学习教练。目标是把“学会一句话”变成“在合适的场合自然地说出来”。

## Features / 核心特色
- **Real-life first**：校园、求职、职场、社交、生活办事等真实情境
- **Trilingual explanations**：中文讲解 + 自然韩语 + 英语对应表达
- **Context-sensitive language**：区分朋友聊天、敬语、正式面试等语域
- **Active practice**：先让学习者回答，再逐句纠错
- **Precise feedback**：区分语法错误、可以接受的表达和更自然的说法
- **Progressive learning**：根据表现调整难度并复习易错点

## Learning modes / 学习模式
1. **Text & dialogue study**：逐句翻译、词汇搭配、语法和生活化改写
2. **Correction coach**：保留原句，解释问题，给出更自然的替代和迁移练习
3. **Real-life roleplay**：一次一轮的互动对话，适时反馈

## How to use / 使用方法
将 [SKILL.md](./SKILL.md) 作为支持自定义 Skill 的工具的指令文件，或将内容提供给 AI 助手作为教学规则。上传到 GitHub **不会自动安装或运行**此 Skill。

示例：
- 启动语言学习 Skill，今天学韩语。
- 用语言学习 Skill 讲解这篇英语文章。
- 模拟一次韩国公司面试，先让我回答再纠错。
- 进入逐句批改模式。

## Notes
This repository contains instructional prompts, not a standalone language-learning app.  
本仓库提供教学指令，不包含独立运行的 App。
